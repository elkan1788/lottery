# C9 Lottery Web

一个面向活动现场使用的网页抽奖系统，参考 [design-prd/design-effect.png](/Users/elkan/CodexWorkSpace/C9-Lottery-v2/design-prd/design-effect.png) 的视觉风格，主打复古霓虹、跑马灯、高亮弹窗的沉浸式抽奖体验。

## 项目背景

该项目用于搭建一个可部署在 GitHub + Vercel 的在线抽奖网页。前台提供大屏抽奖体验，后台提供基础奖品管理和中奖名单查看能力。系统使用 PostgreSQL 存储数据，不单独部署传统后端服务，而是基于 Next.js 的服务端能力完成数据读写与管理操作。

## 核心功能

- 前台抽奖主页
- 花名输入后参与抽奖，支持同一花名多次抽取
- 跑马灯式奖品高亮跳动动画
- 中奖结果弹窗展示，突出“恭喜中奖”效果
- 实时滚动展示最近中奖名单
- 展示字段包括：花名、奖品名称、几等奖、中奖时间
- 中奖时间按东八区展示，精确到分钟
- 简单后台登录页
- 后台奖品管理：新增、编辑、上下架、库存配置、概率配置、图片配置
- 后台中奖名单查看

## 技术方案

- 前端框架：Next.js
- UI：React + Tailwind CSS
- 数据库：PostgreSQL
- ORM：Prisma
- 部署：Vercel
- 环境变量文件：`.env.local`
- 管理后台认证：环境变量账号密码 + Next.js 服务端校验

## 数据范围

建议至少包含以下数据对象：

- 奖品
- 中奖记录
- 抽奖活动配置
- 管理员登录配置（通过环境变量提供，不落库）

## 抽奖规则说明

- 每个奖品具备独立中奖概率权重
- 每个奖品具备独立库存数量
- 抽奖时仅在“已上架且库存大于 0”的奖品范围内参与计算
- 抽奖为百分之百中奖
- 抽奖引擎按权重进行随机，并在命中后扣减库存
- 当高价值奖品库存耗尽后，系统自动基于剩余奖品重新计算可中奖池
- 所有可抽取结果均为真实奖品，不设置“谢谢参与”

## 环境变量示例

请在 `.env.local` 中配置：

```env
PG_DATABASE_URL=
ADMIN_USERNAME=
ADMIN_PASSWORD=
NEXT_PUBLIC_APP_NAME=C9 Lottery
NEXT_PUBLIC_RESULT_COUNTDOWN_SECONDS=5
APP_TIMEZONE=Asia/Shanghai
```

## 管理后台使用说明

### 1. 启动项目

在项目根目录运行：

```bash
npm run dev
```

默认访问地址为：

- 前台首页：`http://localhost:3000/`
- 后台登录：`http://localhost:3000/admin/login`
- 奖品管理：`http://localhost:3000/admin/prizes`
- 中奖名单：`http://localhost:3000/admin/winners`

### 1.1 打开前台抽奖页

访问 `/` 即可进入抽奖主页。当前前台页面已实现：

- 花名输入与开始抽奖交互
- 奖品宫格展示与跑马灯高亮效果
- 基于真实抽奖结果停留的高亮动画
- 中奖揭晓区，展示中奖人、奖品图片、奖品名称、等级和时间
- 最近中奖名单滚动播报

### 2. 登录后台

后台登录使用 `.env.local` 中配置的以下环境变量：

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

访问 `/admin/login` 后，输入上述账号密码即可进入管理后台。

### 3. 奖品管理

当前后台奖品管理页支持以下能力：

- 查看奖品列表
- 按奖品名称搜索
- 按上架状态筛选
- 按等级、库存、更新时间排序
- 新增奖品
- 编辑已有奖品
- 配置奖品图片
- 配置中奖权重
- 配置库存数量
- 配置上架/下架状态

#### 新增奖品

在 `/admin/prizes` 页面填写以下内容后提交：

- 奖品名称
- 等级
- 中奖权重
- 总库存
- 奖品图片
- 是否上架

说明：

- 奖品图片采用本地文件上传方式
- 上传成功后，图片会保存到 `public/uploads/prizes/`
- 新增奖品时，系统会自动将剩余库存初始化为总库存

#### 编辑奖品

在奖品列表点击“编辑”后，可修改：

- 奖品名称
- 等级
- 中奖权重
- 总库存
- 奖品图片
- 上下架状态

提交成功后，页面会返回奖品新增状态，方便连续录入下一条奖品。

### 4. 中奖名单查看

在 `/admin/winners` 页面可查看最近中奖记录，支持：

- 按花名搜索
- 按奖品名称搜索
- 按等级筛选
- 切换最近 20 / 50 / 100 条记录

中奖时间统一按东八区格式展示。

## 设计说明

- 主页面参考设计稿整体风格进行还原
- 页面主体布局正常排版实现，不以弹窗方式承载整个页面
- “恭喜中奖”仅作为抽奖结果弹窗出现
- 动效重点放在奖品跑马灯、高亮边框、发光按钮、中奖弹层
- 中奖名单采用单行滚动播报样式，仅展示时间，不展示日期
- 库存为 0 的上架奖品仍保留前台展示与跑马灯高亮效果，以增强现场氛围
